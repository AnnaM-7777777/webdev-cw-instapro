# Instapro

MVP социальной сети для обмена фотографиями

## Реализованная фунциональность

Интегрирована верстка списка постов с API,
Реализована страница добавления поста (только при авторизации),
Реализована страница с постами конкретного юзера (с авторизацией и без),
Реализован функционал лайков (только для новых постов).

## Дополнительно

Реализована кнопка удаления своего поста
